# sns-covers

SNSツール(sns-poster・デスクトップ)で投稿する Instagram リールの「表紙画像」の公開置き場です。管理は発信担当。

## 置いてよいもの
- リールの表紙画像だけ(JPEG・9:16・1080x1920・8MB以下)

## 置いてはいけないもの
- コード、鍵、パスワード、お客さんの情報
- 投稿前に見せたくない画像(このリポジトリは公開で、誰でも見られます)

## 使い方
1. `<アカウント名>/<日付>_<題>.jpg` の名前で置く(半角英数字)。
2. `https://raw.githubusercontent.com/TAKA1040/sns-covers/main/<そのパス>` が `200`・`image/jpeg` で取れるか確かめる。
3. 投稿の原稿の `cover_url` にそのURLを書く(SNSツールはこのリポジトリのURLだけ受け付ける)。
4. 画像を差し替えるときは、ファイル名を変える(ツールは実物を照合しない)。

詳しい手順: 社内の `instagram-reel-cover-howto.md`(発信担当の `_ツール`)。
`test/` は 2026-10-30 の動作確認用の画像です。
